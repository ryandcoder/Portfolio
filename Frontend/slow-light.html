Personal project

Slow Light

A black-and-white photography album that opens on a single cover photo and lets visitors like and comment on every picture.

Overview

Most photo sites are a grid of thumbnails to skim. I designed Slow Light as an album you move through slowly: it opens on one cover photo, then the pictures appear as you scroll.

I wanted it to be creative and stylish but still simple, so I kept it monochrome and let the photographs do the work. Every photo can be liked and commented on, which turns the album into something visitors can respond to.

What it does

  • Cover-first opening

    The first screen is a single cover photo, like the front of a magazine or a film still.

  • Scroll animation

    The album unfolds as you scroll, so the pace of the photos is controlled by the visitor.

  • Likes on every photo

    Visitors can like any picture, and the count is saved.

  • Comments on every photo

    Visitors can leave a comment under any picture.

  • Black-and-white design

    A muted, non-vibrant palette with a film and magazine feel.

  • Simple by design

    A stylish look without clutter, so nothing competes with the photos.

Design direction

  • One cover photo first. The opening screen sets the mood before any content appears.
  • Monochrome only. Black, white and greys keep attention on light and shadow in the photographs.
  • Motion with a purpose. The scroll animation paces how the photos arrive instead of decorating the page.
  • Interaction stays quiet. Likes and comments are available on every photo without taking over the layout.

How it is built

Frontend
Static site · Vercel
→
API

→
Database and images
Supabase

The site itself is static and hosted on Vercel. A small PHP API on Render handles likes and comments, and Supabase stores the data and the photos. I compared other options for the database and image storage before choosing Supabase to keep everything in one place.

What I learned

  • Designing a restrained, monochrome style where the photographs do the work.
  • Using scroll animation to set the pace of a page rather than to decorate it.
  • Building a PHP API for likes and comments and connecting it to a hosted Supabase database.
  • Deploying a static front end, an API and a hosted database as three separate pieces that work together.
