Overview

IT support teams handle large numbers of tickets, but the raw data rarely shows where time is lost or what needs attention. I built SupportIQ to answer questions like these: which issues come up most, how are tickets spread across agents, and what is changing over time?

I wanted it to look like a professional internal analytics tool, not a school exercise. Every chart is introduced by a plain-language insight sentence, so a manager can read the finding before reading the graph.

What it does

  • Interactive dashboard

    Charts and summary figures built with Recharts, with filters to narrow the data.

  • Written insights

    Short insight sentences above the charts that explain what the data shows.

  • CSV upload

    Bring your own ticket data and analyze it with the same tools.

  • Export and reports

    Take the results out of the app for sharing and reporting.

  • Analytics engine

    A Python layer using Pandas and NumPy that cleans and summarizes the data before the API serves it.

  • Light and dark mode

    An editorial look with a warm paper background, serif headlines, and a deep teal accent.

How it is built

→
Database
PostgreSQL on Neon

I built it in phases, starting with the database and data loading, then the analytics engine, the API, the dashboard, filters, insights, CSV upload, export and reports, and finally tests and documentation. Docker Compose runs the whole stack locally with one command.

The data

SupportIQ uses three CSV files: agents, merchants, and tickets. They come from the open ITSM ticket dataset by drapertoby, which I loaded into PostgreSQL for analysis. Thank you to the author for sharing it.

What I learned

  • Turning a raw dataset into a clean database, then into questions a business would ask.
  • Designing a REST API that keeps the analysis on the server and sends the frontend only what it needs.
  • Presenting data so a reader gets the finding first and the chart second.
  • Deploying three connected services (frontend, API, and database) and getting them to work together.
