PeoplePulse

An employee attrition analytics dashboard that helps HR teams see who leaves, where, and what the data suggests.

Overview

Losing employees is expensive, and HR teams often learn about the pattern only after it has happened. PeoplePulse explores an HR dataset to show where attrition is highest and which employee groups stand out.

I paid special attention to not overstating what the data proves. The dashboard is built to point HR toward questions worth investigating, not to claim causes.

What it does

  • Attrition overview

    Headline figures and charts that show how many employees left and how that changes across the workforce.

  • Group comparisons

    Compare attrition between employee groups to find where it is higher or lower.

  • Dynamic insights

    Insights and recommendations are calculated from the data every time. None of the text is hardcoded.

  • Safe comparisons

    Groups with fewer than 20 employees are not compared, so small samples do not create misleading results.

  • Print to PDF

    Turn the dashboard into a clean report to share with others.

  • Comfortable dark theme

    A dark mode that is easy on the eyes instead of pure black.

My analytical rules

  • Correlation is not causation. The dashboard shows patterns and says so plainly instead of claiming reasons.
  • Minimum group size of 20. Small groups are left out of comparisons.
  • No hardcoded conclusions. Every insight is computed from the current data.
  • No prediction model, on purpose. I focused on describing what happened before trying to forecast it.

The data

PeoplePulse uses the IBM HR Analytics Employee Attrition & Performance dataset: about 1,470 employee records with 35 columns. It is a fictional dataset created for analysis practice, so nothing here describes a real company or real people.

What I learned

  • How to present HR data responsibly: showing patterns without implying causes.
  • Why sample size matters, and how a minimum group size protects readers from noise.
  • Generating insight text from the data itself so it stays correct when the data changes.
  • Packaging a multi-part app with Docker Compose so it is easy to run anywhere.

Next improvements

Attrition prediction, employee segmentation, time-based HR data, and cost-of-attrition analysis.
